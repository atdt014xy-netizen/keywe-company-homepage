# StoreControl 모바일

Flutter Android 앱입니다. 기본값은 네트워크를 호출하지 않는 데모 모드입니다.

실행·APK·AAB 명령은 [Windows 문서](../docs/windows.md), Firebase와 실제 매장 연결은 [계정 설정](../docs/accounts.md)을 참조하세요.

문자열 리소스는 `lib/strings.dart`, Firebase 공개 설정은 `config.live.example.json`, 데이터 모델과 독립 저장소는 `lib/model.dart`와 `lib/repository.dart`에 있습니다.
